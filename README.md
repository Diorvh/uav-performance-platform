# 无人机飞行仿真平台使用说明

本平台包括悬停续航仿真程序、动力系统力效数据库和电芯放电特性数据库，用于管理电机桨叶台架实验与单电芯放电实验，并根据所选数据、电池组配置和整机参数计算悬停过程中的电压、电流、转速及耗电量。

| 功能 | 启动页入口 | 主要用途 |
|---|---|---|
| 悬停续航仿真程序 | 悬停续航仿真 | 配置电池组和推进模型，设置飞行参数，计算与导出结果 |
| 动力系统力效数据库 | 力效数据库 | 查询、比较电机桨叶实验，管理重复实验的采用标记 |
| 电芯放电特性数据库 | 电池数据库 | 查询具体电芯及其放电实验，比较曲线和查看实验条件 |


代码与使用说明采用 [MIT 许可证](LICENSE)；发布的实验数据库采用 [知识共享署名 4.0 国际许可协议](DATA_LICENSE)，具体范围见 [数据许可说明](DATA_LICENSE_NOTICE)。用户自行导入的数据和个人电池组不会自动公开。

## 1 安装与启动

### 1.1 安装运行环境

软件需要 Python 3.11 或更新版本，并包含 Tkinter 图形界面组件。以下步骤适用于 Windows 源码运行方式。在项目根目录打开终端，执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### 1.2 配置实验数据库

从本仓库的“发布版本”（Releases）页面下载与代码版本配套的 `uav-databases-版本号.zip`，解压到项目根目录，使以下两个文件位于：

```text
data/force_efficiency.sqlite3
data/battery_discharge.sqlite3
```

附件同时提供数据库清单和校验值。更新数据库前请备份自己的数据；不要直接覆盖已经加入个人实验的数据库。当前源码包不包含完整数据库，也不包含原始实验表格。

### 1.3 启动软件

双击 `启动无人机性能平台.cmd`，或者运行：

```powershell
.\.venv\Scripts\python.exe launch.py
```

启动页可分别打开“力效数据库”“电池数据库”和“悬停续航仿真”。本文沿用这些界面名称说明操作位置。

## 2 样例运行

### 2.1 载入与计算

在启动页打开“悬停续航仿真”，依次点击“载入样例”和“运行仿真”。载入会替换当前窗口的输入并清除旧结果，但不会保存或覆盖个人电池组模型。

### 2.2 样例配置

样例采用发布数据库中的实测数据，配置如下：

- 力效：HSKRC 2205-1700kV 电机、GF 7036F-2 桨叶；8.1 V 和 11.1 V；采用显示编号 076、077 的两组实验。
- 推进模型：共享电压指数拟合，允许 7.5～12.6 V 电压外推。
- 电芯：其他分类下的“半固态-1”，数据库型号为 10.6Ah，选用实测容量约 10.8109 Ah 的放电实验。
- 电池组：3 串 1 并、整包实测重量 346 g；单电芯增量电阻设为 0，整包线束电阻为 14 mΩ，整包截止电压 7.5 V。

线束电阻为 14 mΩ，因此程序使用的整包增量电阻为 14 mΩ，总内阻 20 mΩ 。

| 飞行参数 | 样例值 |
|---|---:|
| 机体裸重 | 211 g |
| 其他载荷 | 0 g |
| 旋翼数量 | 4 |
| 等效推力系数 | 1.05 |
| 整机用电器功率 | 5 W |
| 初始窗口剩余容量 | 100% |
| 整包电流限制 | 0，关闭 |
| 积分步长 | 1 s |
| 最大计算时间 | 120 min |

### 2.3 结果查看

参考算例的计算时长约为 **87.53 min**。默认显示电池端电压、单电机转速、电池总电流和动力净力效四项时序曲线。

## 3 悬停续航仿真程序使用

### 3.1 操作流程

一般使用流程为：选择推进数据 → 配置电池组 → 设置飞行参数 → 运行仿真 → 查看停止原因与计算结果 → 导出数据。

仿真程序左侧包含“测试数据”“飞行参数”和“CSV 口径”三个页签。数据库选择与电池组配置在“测试数据”页完成；整机参数在“飞行参数”页填写；导入自测推进 CSV 前，应在“CSV 口径”页确认测试电压和功率定义。

推进数据可从力效数据库选择，也可直接导入自测 CSV，格式见第 4.4 节。放电数据可从电芯数据库选择，也可导入单电芯或整包 CSV，操作见第 5.4、5.5 节。

### 3.2 选择推进数据

1. 点击“读取推进数据库”，打开力效数据库。
2. 选择同一电机、桨叶和电调设置下的实验组，可按住 Ctrl 或 Shift 多选不同电压层。
3. 选择“共享电压指数拟合”或“实测分层插值（对照）”。是否允许外推需要明确勾选。
4. 点击“载入选中曲线”。重复实验必须先在力效数据库窗口确定采用组，不能把重复组当成不同电压层混用。

共享指数拟合需要至少两个电压层，每层至少三个点，且共同推力区间至少约 50 gf。缺少空载电流、混用硬件、同电压选入多组实验等情况会被拒绝。

### 3.3 建立与保存电池组

1. 在“测试数据”页打开“电池组模型库”，点击“新建电池组”。
2. 在“单电芯放电数据”页点击“从电芯数据库选择电池 / 实验”，选择具体电芯，再选择具体实验。只有资料、没有放电曲线的电芯不能直接建模。
3. 核对实验的参考电流、容量窗口、末端电压和截止依据。如果曲线提示短时电流波动或不完整窗口，先阅读提示再决定是否采用近似；中途停流或变化过大的实验不能用于单参考电流模型。
4. 在配置页填写名称、串联数、并联数、重量、电阻和截止电压。整包实测重量优先；留空时按电芯数量和附加重量估算。
5. 保存后用于仿真。以后可从模型库选择，也可另存为新的电池组。

电池组保存在本地 `data/battery_pack_models.sqlite3`，不包含在公共实验数据库附件中。电池组关联的是单个电芯的某次实验，不会自动混合多节电芯或多次测试。源实验被修改或删除后，需要重新选择。

### 3.4 设置飞行参数

在“飞行参数”页填写以下内容。使用电池组模型时，电池质量、参考电流、整包增量电阻和截止电压由模型带入；需要修改这些参数时，应编辑电池组配置后重新载入。

| 参数 | 填写要求 |
|---|---|
| 机体裸重 | 不含电池和其他载荷的机体质量，单位 g |
| 其他载荷 | 未计入机体裸重的附加载荷质量，单位 g |
| 旋翼数量 | 实际参与悬停的旋翼数量，填写正整数 |
| 等效推力系数 | 纯悬停取 1；大于 1 表示增加经验等效负载 |
| 整机用电器功率 | 飞控、图传等整机用电器的合计功率，单位 W |
| 初始窗口剩余容量 | 相对于所选放电实验窗口的初始剩余容量百分比 |
| 整包电流限制 | 限制整包总电流，单位 A；填写 0 表示关闭此限制 |
| 步长 | 容量积分的最大时间步长，单位 s |
| 最大计算时间 | 本次仿真的最长计算时长，单位 min |

### 3.5 运行与停止

完成数据选择和参数设置后，点击“运行仿真”。计算期间输入控件锁定；点击“停止”可中止计算并保留已完成部分。

计算结束后，首先检查停止原因，再读取计算时长。达到截止电压、电流限制、数据边界、实验容量窗口末端或时间上限具有不同含义。修改输入会清除已有结果；修改测试电流或 CSV 功率定义等条件后，需要重新导入对应数据。

### 3.6 查看与导出结果

可勾选多个曲线，选择原值分图或归一化叠加，并用鼠标读取数值。“耗电分项与模型提示”显示动力净耗电、用电器耗电以及模型范围。

“导出结果 CSV”保存时序结果；“导出追溯记录”保存参数、源数据、模型和软件版本等信息。追溯文件可能包含你的本地路径和私人配置，公开分享前请自行检查。修改输入后，旧结果会清空，需要重新运行。

## 4 动力系统力效数据库使用

### 4.1 查询实验组

在启动页打开“力效数据库”。通过搜索框或“条件筛选”中的电机、桨叶、测试日期、标称电压筛选实验；点击“清除筛选”恢复完整列表。

选择实验组后，右侧“数据组设置”显示相关测试条件，下方显示测量点和曲线。比较前应核对电机型号、桨叶、电压、空载电流以及电调设置。

### 4.2 比较曲线

按住 Ctrl 或 Shift 选择多个实验组，在“横轴”和“纵轴”中选择需要比较的参数，点击“重绘”更新曲线。不同硬件的实验可以用于查看比较，但不能合并为仿真程序中的同一个推进模型。

### 4.3 管理重复实验的采用标记

重复实验在列表中显示 R 编号。对于同一重复组，选择拟采用的实验后点击“标记为采用”；需要撤销时点击“取消标记”。同一重复组只允许采用一条实验。

采用标记会保存到本地力效数据库，影响后续仿真时可选择的实验。修改标记后，应在仿真程序中重新读取数据库。非重复实验可按其有效数据范围参与建模。

### 4.4 导入自测力效数据用于仿真

用户自测数据可整理为 CSV，通过仿真程序的“导入推进 CSV”使用。该操作不写入实验数据库。

推荐文件格式如下。所列数值仅用于说明字段格式，不代表实测数据：

```csv
voltage_V,rpm,thrust_g,power_W
8.1,5000,100,12
8.1,6000,150,20
8.1,7000,200,30
11.1,5000,100,13
11.1,6000,150,21
11.1,7000,200,32
```

- 每行是一个单电机、单桨工作点；不要填入四个电机的合计推力或功率。
- `thrust_g` 表示克力，若使用牛顿则改为 `thrust_N`。不要把毫牛直接填入牛顿列。
- `power_W` 是功率，不是电流。也可使用 `efficiency_g_per_W` 力效列；同时提供功率和力效时，二者必须相符。
- 保留真实测试电压。同一个文件可以包含多层电压，但应是同一套硬件和电调设置。
- 在“CSV 口径”页选择功率含义，再点击“导入推进 CSV”。净功率已扣空载；总电功率需要扣除 `V×I0`；轴功率需要先换算为电输入功率，再扣空载。
- 使用总电功率或轴功率时，提供 `no_load_current_A` 列，或者填写空载电流后备值。不同电压的空载电流不同时，应逐行填写。净功率数据不要再次扣空载。
- 缺少电压列时使用界面填写的测试电压；单电压数据采用电压无关近似，不能据此验证低压下的最大推力。

**当前 CSV 入口使用分层插值，不会自动进行共享指数拟合，也不会自动写入力效数据库。** 共享指数拟合入口是“读取推进数据库”。力效数据库现有的 Excel 扫描器针对既定台架表格布局，并不是任意 Excel 文件的通用导入器；新格式应先整理为上述 CSV 使用。

## 5 电芯放电特性数据库使用

### 5.1 查询电芯资料

在启动页打开“电池数据库”，依次选择“电池类型”“电池类别 / 型号”和具体电池编号。半固态等非 18650、21700 类型归入“其他”。列表中的曲线数用于判断该电芯是否具有已收录的放电实验。

“电池资料”页可查看基本资料、参考测试和原表资料。“全部电池一览”用于汇总查询；“刷新数据库”用于读取数据库的最新内容。公开版本已清理购买资料和私人原表字段，相应栏目可能为空。

标称容量来自电芯资料，曲线实测容量与能量来自放电采样积分，二者应分别理解。仅有资料而没有曲线的电芯不能直接用于建立放电模型。

### 5.2 查看与比较放电实验

在电池列表下方选择实验，可按住 Ctrl 或 Shift 多选。各页签用途如下：

| 页签 | 用途 |
|---|---|
| 曲线比较 | 选择横纵坐标，比较不同实验的放电过程 |
| 实验信息与异常 | 核对测试电流、起止条件、截止电压依据及数据异常 |
| 原始点与计算值 | 查看采样时间、电压、电流及计算结果，按时间定位最近采样点 |

开始电压和末端电压应以实际记录为准。截止电压是实验条件字段；使用前应核对其来源以及与末端实测电压的差异，不应统一改写为 4.2 V、2.5 V 或 2.8 V。

### 5.3 设置代表实验与导出曲线

选中实验后，可点击“设为代表实验”或“取消采用”管理数据库中的代表标记。选中曲线用于显示，不等于已经设置采用标记；仿真建模时仍须明确选择具体电芯和具体实验。

在数据库显示模式下，选中一条符合导出条件的实验，点击“导出所选仿真曲线”。程序将带有实验身份、元信息和采样点的 JSON 文件保存到数据库所在目录的 `simulation_exports` 文件夹，并显示完成提示。

该 JSON 为结构化曲线记录，不是两列电池 CSV。使用本平台进行仿真时，可直接在“电池组模型库”中选择同一实验，无需先导出再导入。导出条件通过也不代表该实验必然满足恒流模型的全部要求，仿真载入时仍会检查电流波动、时间间隔和截止条件。

### 5.4 导入自测单电芯恒流曲线

整理两列 CSV：时间和带载电压。以下仅为格式示意，实际应提供完整测量窗口：

```csv
time_s,voltage_V
0,4.18
60,4.10
120,4.04
```

1. 打开“电池组模型库”，新建电池组并填写电芯型号。
2. 进入“单电芯放电数据”，填写这次实验的**单电芯真实恒流值**，点击“导入单电芯 CSV”。
3. 填写串并联数、重量、单体增量电阻、整包线束电阻和单体等效截止电压，再保存并用于仿真。

CSV 可以由 Excel 另存为 UTF-8 格式。时间以秒为单位并严格递增，电压以伏为单位；至少两个有效采样点。首个样本是该测试窗口的起点，不要求其电压恰好为 4.2 V，也不会把末端强制补成 2.5 V 或 2.8 V。

此两列入口按手填恒流积分容量，**不会读取额外电流列来修正变流过程**。不要把变流、停流、充放电混合数据当作恒流曲线导入，也不要通过插值伪造缺失的放电尾段。

### 5.5 导入自测整包恒流曲线

在仿真窗口选择“改用整包 CSV”，填写整包参考恒流，再点击顶部“导入电池 CSV”。格式同上，但电压和电流均是整包值。随后手动填写整包重量、增量电阻和截止电压。此入口不进行串并联换算，不能将单电芯电压直接作为整包电压。

### 5.6 原始记录预览与实验入库

电池数据库窗口可以只读预览其支持的放电 Excel 或 CSV 原始记录，显示可识别的条件和曲线问题。**预览不会写入数据库。** 当前图形界面不提供任意原始表格的一键入库功能。

自测数据可通过上述单电芯 CSV 与整包 CSV 入口用于续航计算；单电芯曲线会随保存的电池组保存在个人模型库中。若要把实验正式加入实验数据库，需要先核对电芯身份、字段映射、重复时间点、截止条件及采用标记，再通过数据库导入程序处理，不能直接把预览结果视为已入库。

## 6 仿真模型介绍

### 6.1 质量、推力与功率

模型假设准稳态悬停、各旋翼相同且均分推力。总质量只计入一次电池质量；标准重力下，以克计的质量与所需克力数值相同：

```text
总质量 = 机体裸重 + 电池质量 + 其他载荷
单桨推力 T = 总质量 × 等效推力系数 / 旋翼数 N
单桨动力净功率 = 测试电压 ×（测试电流 − 空载电流）
整机功率 P(V) = N × 单桨动力净功率 + 手动用电器功率
整包电流 I = P(V) / V
```

纯悬停的等效推力系数取 1；大于 1 仅增加经验负载，如需模拟爬升或机动，可根据经验设定系数。飞控、图传等用电器功率是整机合计值，不再乘旋翼数。已扣除但实飞仍存在的耗电，需要计入手动用电器功率，程序不会自动补回台架空载基线。

### 6.2 推进系统模型

**分层插值**：每个电压层内按推力对净功率和转速线性插值，再在相邻电压层之间插值，使用范围受测量数据限制。

**共享电压指数拟合**：

```text
净力效 η = A × (T / 300)^c × (V / 9)^b
b = −0.1117351442
单桨动力净功率 = T / η
转速估算：T = k × 转速²
```

其中推力单位为 gf，电压单位为 V，力效单位为 gf/W。A、c 根据本次选中的实验点在对数空间拟合；b 来自既有实验族的探索结果，当前不会重新拟合。转速关系单独拟合，因此固定推力下，估算转速可以保持不变。

外推启用后，电压范围限于 7.5～12.6 V，推力仍受选中实验的总体范围约束，外推样本会明确标记。

### 6.3 放电曲线与串并联换算

数据库曲线根据实测电流作梯形积分，得到已耗容量 q，再按容量查找带载参考电压。直接导入的两列恒流 CSV 则使用手填参考电流换算容量。两者都是实测带载基线，不是开路电压曲线。

串联数为 S、并联数为 P 时，假设电芯一致、并联均匀分流：

```text
整包容量窗口 = P × 单电芯容量窗口
整包参考电流 = P × 单电芯参考电流
整包参考电压 = S × 单电芯参考电压 − 整包参考电流 × 线束电阻
整包增量电阻 = S / P × 单电芯增量电阻 + 线束电阻
整包截止电压 = S × 单体等效截止电压
```

界面输入电阻使用 mΩ，计算时换算为 Ω。整包实测重量优先，否则采用 `S×P×单体重量＋附加重量`。单体截止输入是整包停止阈值的等效设定，不代表已经模拟了每节电芯的不一致性或保护板动作。

### 6.4 电压、电流联立与时间积分

```text
V = V参考(q) − R增量 × (I − I参考)
I = P(V) / V
下一步已耗容量 = 当前已耗容量 + I × 时间步长 / 3600
```

功率和压降都与当前电压、电流有关，所以每个时间点先求满足两个方程的可用高电压解，再显式推进容量。分层插值模型逐段求代数根，拟合模型使用一维求根；容量随时间的推进采用显式积分。参考曲线中的线束基线压降已经扣除，增量项不会再次重复扣除同一参考压降。
